# CREDO Archive

This directory keeps assets that are not part of the current default runtime path.

- `legacy_audio/`: deprecated local audio pools. These are ignored by git because they can be regenerated and are large.
- `legacy_manifests/`: small probe manifests and one-off manifest experiments kept for traceability.
- `legacy_scripts/`: replaced generation scripts that should not be used for the current pipeline.
- `tts_style_examples/`: old TTS comparison samples. These are reference artifacts, not active runtime inputs.

Current runtime assets remain outside this archive, especially:

- `AI_NPC_System/fasttrack_assets/text/professor_lab_maid_dataset_pool_v1/`
- `AI_NPC_System/fasttrack_assets/audio/expressive_interjection_bundle/`
