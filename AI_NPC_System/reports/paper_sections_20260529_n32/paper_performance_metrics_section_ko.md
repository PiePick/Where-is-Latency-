# 논문 성능지표 파트 초안: 길이 구간별 모듈 지연시간

## 계측 방법

시스템 성능은 CREDO 런타임에서 생성된 모듈 단위 로그를 기반으로 분석하였다. 로그는 각 턴의 모듈명, stage, 소요 시간(ms), 입력 또는 출력 글자 수, 실험 조건을 기록한다. 본 분석에서는 서버 재시작 및 UI 수정이 완료된 이후의 안정 구간인 `2026-05-29T03:36:00+09:00` 이후 로그만 사용하였다. 이는 개발 중간의 실패 로그와 재시작 로그가 성능 평균에 섞이는 것을 막기 위한 절차이다.

SlowTrack은 실제로 합성되어야 하는 최종 본문 응답의 글자 수를 기준으로 구간화하였다. FastTrack은 사용자의 직접 입력 또는 채팅 batch 입력 글자 수를 기준으로 구간화하였다. 길이 구간은 10-100자, 100-200자, 200-500자, 500-1000자로 나누었다. 관측치가 없는 구간에는 추정값을 넣지 않고 결측으로 처리하였다.

## 성능 결과 해석

SlowTrack의 관측 응답은 대부분 200-500자 구간에 분포하였다. 이 구간에서 LLM 응답 생성 평균은 1474.9 ms, TTS 음성 합성 평균은 825.4 ms, 두 모듈 합산 평균은 2300.3 ms였다. 반면 FastTrack은 500-1000자 입력 구간에서도 전체 평균 17.3 ms로 동작하였다. 따라서 CREDO의 핵심 기여는 SlowTrack 자체의 계산 시간을 없애는 것이 아니라, 긴 응답이 준비되는 동안 사용자가 감지하는 초기 공백을 수십 ms 수준의 FastTrack 반응으로 덮는 데 있다.
